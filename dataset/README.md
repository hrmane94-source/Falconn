# FALCON Dataset

This directory documents the dataset-generation and annotation strategy.

## Planned document classes

- Aadhaar
- PAN
- Passport
- Visa / visa stamps
- Driving Licence
- Exam hall tickets

## Current target inventory

Use the actual inventory, not inflated numbers:

- Aadhaar: up to 100 genuine + up to 100 forged/synthetic
- Other document classes: approximately 150–200 genuine + 150–200 forged/synthetic per class

These are project inventory targets, not model-performance claims.

## Forgery categories

Examples:

- DOB alteration
- Name/field alteration
- Face/photo replacement
- Stamp manipulation
- Expiry-date alteration
- Copy-paste/splicing
- Recompression/resampling
- Synthetic document generation

## Safety

Do not upload real people's identity documents, Aadhaar numbers, passport numbers,
addresses, or other personal data to this repository.

Prefer synthetic, redacted, consented, or legally usable material.
